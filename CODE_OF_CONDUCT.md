# Community code of conduct

Be considerate, constructive, and welcoming. Discuss evidence and code rather
than attacking people. Respect different backgrounds and levels of experience.
Harassment, discriminatory language, threats, and disclosure of another person's
private information are unacceptable.

Maintainers may edit or remove harmful contributions, close discussions, or
restrict participation. Report public conduct concerns to repository maintainers;
for sensitive concerns, use an available private contact on a maintainer's GitHub
profile rather than posting private information in an issue. Maintainers should
handle reports discreetly and explain moderation decisions where appropriate.
